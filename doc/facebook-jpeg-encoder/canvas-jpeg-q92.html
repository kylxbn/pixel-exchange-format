Canvas JPEG Export

This page loads ../artifacts/facebook-jpeg-encoder/probe.png into a canvas and exports it as JPEG with browser quality 0.92.

Browsers do not provide a standard API to force JPEG chroma subsampling, so 4:2:0 is not directly specifiable here. Most browsers use their built-in JPEG encoder defaults.

Open this page through a local HTTP server, not via file://. Direct file access often taints the canvas and causes “The operation is insecure.”
